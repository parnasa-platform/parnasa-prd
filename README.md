# Parnasa Product Requirements

The published copy of the Parnasa product requirements document, organised by use case.

Read it at https://parnasa-platform.github.io/parnasa-prd/

## Comments

Every use case and every requirement has a Discuss button, and the Comments button in the top bar is for the document as a whole. Comments are stored as GitHub Discussions in this repository and need a GitHub account.

## Changes

This repository holds only the generated page. Do not edit `index.html` here: it is replaced on every publish. The source and the build scripts are in `unified-prd/` in the parnasa-docs-internal repository.
